## Homework — pairs

This kicks off [Assignment 2](/tsost/course/assignments/assignment-2/) — your Smart Thing.

Goal: understand your object, what would make it smart, and what it would sound like.

1. Pick an object from the [Lucid.Bar Whitelist](/tsost/course/resources/lucid-bar-whitelist/) — it must have dynamic properties.
2. Conduct an **object-centered study** of your chosen object:
    - One-day object diary
    - Character analysis
    - Inter-thing correspondence
    - Thing-personification
3. Choose a sensor from the [Lucid.Bar Whitelist](/tsost/course/resources/lucid-bar-whitelist/) that connects to how you see the object being smart.

## Before next week

Install the following on your laptop before you arrive:

1. **[Max](/tsost/course/tools/max/)** or **[Plugdata](/tsost/course/tools/plugdata/)** — Max needs a licence or the 30-day free trial. Plugdata is free, with fewer built-in objects
2. **[Arduino IDE](/tsost/course/tools/arduino-ide/)** — download latest version (2.x)
3. **[ESP32](/tsost/course/tools/esp32/)** — add **board support** in Arduino IDE: Preferences → Additional boards manager URLs → add Espressif URL, then install via Boards Manager

See [Arduino IDE](/tsost/course/tools/arduino-ide/) and [ESP32](/tsost/course/tools/esp32/) for step-by-step instructions.
