- Cross-platform: Mac, Windows, Linux

## Plugdata vs Max

Plugdata uses the Pure Data engine under the hood, with a modern interface that closely resembles Max. Most basic patching concepts transfer directly. Some Max-specific objects are not available, but for the purposes of this course — receiving OSC, scaling values, generating sound — Plugdata is fully capable.

## Getting started

1. Download and install from [plugdata.org](https://plugdata.org)
2. Open a new patch
3. Create objects with Cmd+1 (Mac) or Ctrl+1 (Windows)
4. Connect outlets to inlets by dragging

## Relevant to this course

- Receiving [OSC](/tsost/course/tools/osc/) data from your sensor prototype
- Scaling and mapping sensor values to sound parameters
- Basic synthesis and audio output
